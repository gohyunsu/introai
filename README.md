# AI, 연결해서 이해하기

서울대학교 `AI 입문` 수업의 개념 흐름을 직관, 수식, 코드 패턴, 인터랙티브 실험으로 다시 구성한 개인 학습 보조 사이트입니다.

## 구성

- 11개 학습 장: AI의 지도부터 이상 탐지까지
- 장별 인터랙티브 실험과 셀프체크
- KaTeX 수식, 전체 검색, 로컬 진도 저장, 다크·집중 모드
- 모바일·태블릿·데스크톱 반응형 레이아웃

## 로컬 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다. 별도 패키지 설치나 빌드 과정은 없습니다.

## 검증

```bash
npm run check
```

로컬 링크, 장 데이터, 공개 금지 확장자를 확인합니다.

## 공개 자료 정책

이 저장소에는 원본 강의 슬라이드, 강의 코드, 노트북, 데이터셋, 모델 파일을 포함하지 않습니다. `.gitignore`와 검증 스크립트가 `pdf`, `pptx`, `ipynb`, `zip`, `csv`, `npy`, `h5` 등을 차단합니다. 사이트의 설명과 시각화는 학습을 위해 새로 작성했습니다.

외부 영상과 문서는 각 제작자·공식 문서로 연결되며 저작권은 원저작자에게 있습니다.

## 배포

`main` 브랜치에 push하면 GitHub Actions가 소스를 검증한 뒤 GitHub Pages에 정적 사이트를 배포합니다.
