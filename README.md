# Introduction to AI

서울대학교 `AI 입문` 수업의 이론·개념·강의 코드·NVIDIA DLI 실습을 직관, 수식, 계산 예제, 실행 가능한 코드 흐름과 인터랙티브 실험으로 다시 구성한 개인 학습 보조 사이트입니다.

Live site: <https://gohyunsu.github.io/introduction-to-ai/>

## 구성

- 12개 학습 장: AI의 지도부터 NVIDIA 딥러닝 실습과 선택형 이상 탐지 확장까지
- 148개 상세 주제와 75개 이상의 설명용 코드 블록
- NVIDIA DLI 흐름: MNIST, ASL, CNN, 데이터 증강·배포, VGG16 전이학습, LSTM, 과일 분류 평가
- 생선·와인·과일·Fashion-MNIST 강의 코드를 재구성한 단계별 실습
- 장별 인터랙티브 실험, 실패 진단, 셀프체크
- 출처와 라이선스를 표시한 공개 시각 자료 및 개념별 영상
- KaTeX 수식, 전체 검색, 로컬 진도 저장, 다크·집중 모드
- 모바일·태블릿·데스크톱 반응형 레이아웃

## 로컬 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다. 별도 패키지 설치나 빌드 과정은 없습니다.

## 검증

```bash
npm run check
```

로컬 링크, 12개 장의 핵심 이론 용어, 필수 실습과 코드 블록, 시각 자료 메타데이터, 공개 금지 확장자를 확인합니다.

## 공개 자료 정책

이 저장소에는 원본 강의 슬라이드, 강의 코드, 노트북, 데이터셋, 모델 파일을 포함하지 않습니다. `.gitignore`와 검증 스크립트가 `pdf`, `pptx`, `ipynb`, `zip`, `csv`, `npy`, `h5` 등을 차단합니다. 사이트의 설명과 인터랙티브 시각화는 학습을 위해 새로 작성했습니다.

외부 영상과 문서는 각 제작자·공식 문서로 연결됩니다. 저장소에 포함된 공개 이미지의 저작자와 라이선스는 `assets/CREDITS.md` 및 사이트의 각 캡션에 명시합니다.
